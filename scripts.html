Scripts

One-liner deploy with irm | iex. All scripts are open-source, hosted at *.drraypc.com, and safe to inspect before running.

! Always review a script before running it. Open the URL in your browser to read the source - cleanup.drraypc.com, dr-downloader.drraypc.com. Run only in PowerShell 5.1+ on Windows 10/11.

Available Scripts

Cleanup Script System

Clears Windows temp files, browser caches, Windows Update cache, and prefetch data. Outputs a per-category byte summary so you know exactly what was reclaimed. No reboot required.

Run in PowerShell (as Administrator)

PS> irm https://cleanup.drraypc.com | iex
Temp files Browser cache Windows Update cache Prefetch data No reboot needed
// PowerShell 5.1+ - Windows 10/11 view source →
DR Downloader Utility

A lightweight PowerShell file downloader utility. Handles authenticated downloads, progress reporting, and automatic retry on failure.

Run in PowerShell

PS> irm https://dr-downloader.drraypc.com | iex
Progress reporting Auto retry Resume support
// PowerShell 5.1+ - Windows 10/11 view source →

// HOW irm | iex WORKS

irm (Invoke-RestMethod) fetches the script as plain text from the subdomain. iex (Invoke-Expression) executes it in your current PowerShell session.

You can inspect any script first by running irm https://cleanup.drraypc.com without piping - this prints the source without executing it.
